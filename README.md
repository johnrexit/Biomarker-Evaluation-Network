# BEN

**BEN — Biomarker Evaluation Network**

BEN is an experimental research project exploring machine-learning methods
for identifying potential early cancer-related signals in veterinary data.

> BEN is a research prototype and is not a clinical diagnostic tool.

## Current version

Alpha 1.0

## Current focus

- signal preprocessing
- feature extraction
- model evaluation
- cross-validation
- calibration
- robustness testing
